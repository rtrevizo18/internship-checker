# internship-checker
Simple Bash Script that cURLs SimplifyJob's Summer2026-Internship's repo and pings my email when a new job posting is listed

Usage:

Clone the repo, add your own email, make sure you have the dependencies configured and installed, and run the script!

As for dependencies, you can download your package manager's mail program and configure it to have the email sent to yourself. Install jq for json parsing as well!

I'm looking to add more to this, so please let me know if there's any interesting additional features ya'll would like to see added!
